# Who the Model Learns to Fund

A cognitive science senior project (COGS 301, Lehigh University, 2026–27) on how AI screening trained on past exits can lock historical bias into venture funding.

Built by Syeda Tawheeda Huq.

## The pieces

| Folder | What it is |
|---|---|
| `/` | Landing page tying the project together. |
| `ride/` | **Who Gets the Dollar.** A scroll-driven visual: 1,000 dots re-form into each funding statistic and research finding. |
| `machine/` | **The Prototype Machine.** A playable simulation of a prototype-matching AI screener over five funding cycles. See `machine/MODEL.md` for every assumption and `machine/test/sim.test.js` for the check. |
| `research/` | **Research map.** The literature behind the project, organized into four pillars, with counter-evidence and the research gap. |

Everything is plain HTML, CSS and JavaScript with no build step. Open any `index.html` in a browser, or view the live site on GitHub Pages.

## Status

Work in progress. Simulation results show a mechanism under stated assumptions, not measurements of the real venture market. Figures flagged ⚑ on the pages are still being verified against primary sources.
